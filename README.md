# 📚 Library Book Borrow Analysis

## 📌 Project Overview
This SQL project analyzes library borrowing records to understand book issue trends, member activity, and borrowing patterns.

## 🛠 Tools Used
- MySQL
- SQL
- VS Code
- Git & GitHub

## 📊 Analysis Performed
- Total books borrowed
- Most borrowed books
- Active library members
- Borrowing frequency analysis
- Category-wise borrowing trends

## 📂 Project Files
- `Library_Borrowing_Analysis.sql`

## 🚀 Skills Demonstrated
- SQL Queries
- Joins
- Aggregate Functions
- GROUP BY
- ORDER BY
- Data Analysis
